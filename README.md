# obj2svg

Convert OBJ line elements into connected SVG polylines.

`obj2svg` is a command-line utility that reads Wavefront OBJ files containing
line elements and converts them into clean, connected SVG polylines.

## Installation

```bash
cargo install --git https://github.com/username/obj2svg.git
```

## Usage

```bash
obj2svg --help
obj2svg input.obj output.svg
```
